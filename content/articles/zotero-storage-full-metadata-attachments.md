Zotero 弹出存储已满时，多半卡在「已经上传的附件」额度，而不是文献条目坏了，也不等于电脑磁盘写满。适用场景是：条目、笔记、标签仍能保存或仍能同步，但 PDF 等附件上传失败、反复警告配额。处理方向是：先分清不限量的数据同步、受配额限制的文件同步、以及本机磁盘三件不同的事；不要按社区说法删除 storage 目录。先确认本机仍有完整副本并做好备份，再决定是只同步条目、改附件同步方式，还是使用官方存储。依据 [Syncing](https://www.zotero.org/support/sync) 与 [Why is Zotero still saying that my storage is full](https://www.zotero.org/support/kb/storage_quota_and_local_storage)。

## 条目同步和附件同步不是一回事

Zotero 默认把数据存在本机。同步分两块：数据同步合并条目、笔记、链接、标签等，不包括附件；这一块免费且不限量，也可以单独使用、不开启文件同步。文件同步才负责 PDF、音频、视频、图片等附件，可选 Zotero Storage 或 WebDAV。

账号文件配额只计算已上传到 Zotero 服务器的附件，不影响本机继续保存。材料写明：即使在线配额已满，也不会因此禁止在应用里继续保存。所以“提示已满”不等于本机不能用，更不等于条目同步停了。

错位很常见：本机附件远大于免费的 300 MB，一对上文件同步就把已上传额度撑满。刚升级方案或刚删了一批文件，仍可能立刻看到同样提示——因为本机还有更多未上传附件会接着占满额度；必须让本机附件总量低于在线配额，用量显示才会降下去。回收站里的文件在永久删除前仍计入配额，要先清空回收站。

## 先保住本地副本，不要删 storage 目录

配额警告针对在线上传，不是叫你清掉本机库。不要跟随社区删除 storage 目录：那会直接动到本机附件存放处，官方步骤里也没有这一项。更危险的是把整个数据目录直接放进网盘同步文件夹，材料写明这极可能损坏数据库，不应这样做。

低风险顺序：先确认本机库能打开，条目和 PDF 还在。需要防丢失或换机时，先关闭 Zotero，再复制整个数据目录，当作备份或在另一台机器上、同样在关闭 Zotero 后还原。不要在软件打开时让网盘去同步该目录。

若只是不想把附件传到 Zotero 服务器，可继续只用数据同步：在 Sync 偏好设置的 Data Syncing 中填写登录信息。默认同步会在变更后进行；可取消 “Sync automatically”，需要时点工具栏右侧 “Sync with zotero.org” 手动同步。同一条目在多处、同步前被改成冲突版本时，会出现冲突对话框，需选择保留哪一版。新电脑只要配置同一账号，就会拉下在线文库中的数据（不含你未做文件同步的附件）。

## 按需求选择附件同步或官方存储

需要附件也在多设备和网页文库可用时，材料推荐 Zotero Storage：支持群组文库中的文件、可在网页查看附件、设置更直接。免费额度为附件 300 MB，更大方案在存储设置页购买，此处不列价格。升级后若本机总量仍高于新配额，仍会马上再次提示已满，这是额度计算，不是“升级没生效”。

只要个人文库、且机构提供 WebDAV 时：在 Sync 偏好设置填入服务给出的 URL、用户名和密码，协议选 http 或 https（不确定时先试 https），再点 Verify Server。群组文库不能用 WebDAV。第三方 WebDAV 是否稳定取决于对方服务器，Zotero 开发者不为第三方服务器提供支持。

必须用外部网盘只同步附件时，材料允许改用链接文件（linked files），只把附件放在外部同步文件夹，而不是把整个数据目录丢进网盘。

常见失败：没清空回收站就以为腾出了空间；只删掉一部分本机文件，同步后又被其余本地附件填满；把数据目录当普通文件夹交给网盘。替代办法是：本机保存不受在线配额限制；需要多设备附件时再选官方存储或已验证的 WebDAV；不需要附件上云时关闭文件同步、只保留数据同步。
