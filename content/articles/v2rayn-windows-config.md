配置导入成功不等于 Windows 流量已经接管。先确认客户端来源和配置格式，再用固定目标检查系统代理、策略和日志。

## 先固定版本与配置来源

从 [v2rayN 原始仓库](https://github.com/2dust/v2rayN) 查看 README 与发行说明，记录客户端版本、配置文件来源和导入时间。不要在排查过程中同时更换客户端、订阅和网络。

## 导入后检查基本状态

导入一份配置后，先确认节点或出站列表能被解析，再查看当前选择项和系统代理状态。若配置文件为空或字段报错，先回到源文件核对格式，不要直接修改所有字段。

## 用固定目标验收接管

选择一个固定的 HTTP/HTTPS 目标，先测试遵循系统代理的浏览器，再测试目标应用。浏览器有效而应用无效时，应检查应用是否绕过系统代理，而不是立即更换节点。

## 用日志定位最早错误

保留启动时间、目标地址和最早一条错误。DNS 解析失败、连接超时和 TLS 错误分别记录；必要时参考本站的 [FlyClash 代理模式验收](/articles/flyclash-proxy-mode-check/) 对照检查顺序。
